# 🎨 Brand customization

[English](BRANDING.md) · [Português (Brasil)](BRANDING.pt-BR.md)

Ebyte Game Panel ships with an original emblem and configurable product name.

```env
VITE_PANEL_NAME=Ebyte Game Panel
VITE_PANEL_LOGO_URL=/ebyte-logo.png
```

The logo must be in `frontend/public/` or at a public HTTPS URL. Keep the
original Apache 2.0 license and OVH copyright attribution in distributed source
copies. Ebyte branding does not claim OVHcloud endorsement.
